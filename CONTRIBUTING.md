# Contributing

Bug reports, docs fixes, and pull requests are welcome.

1. Open an [issue](https://github.com/ibigsnet/StorageGuard/issues) for discussion when the change is large.
2. Prefer focused PRs against `main`.
3. Test Main free-bar / alert paths on a real array or pool when you change paint or thresholds.
4. If you change capacity math, update the matching notes under `docs/math/`.

Support: [Unraid forum](https://forums.unraid.net/topic/199796-plugin-storage-guard-free-space-thresholds-so-you-know-if-a-failed-disk-still-leaves-room-to-move-data/).
